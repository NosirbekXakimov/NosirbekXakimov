This account is where I send fixes and reviews to projects I depend on: .NET libraries and analyzers, Rust crates, and the tooling behind [bitg](https://github.com/dtwinuz/bitg) and [dtwin.uz](https://dtwin.uz).

### Focus

| Area | What I look for |
|---|---|
| .NET (`EF`, analyzers, ASP.NET) | Bugs I hit in production at scale, with a failing test first |
| Rust (`bitg-core`, input method crates) | Unicode and text-processing edge cases |
| Supply chain (OpenSSF, Sigstore, Actions) | Small changes that make releases verifiable |
| Uzbek language tooling | The 2026 Latin alphabet in fonts, keyboards and spellcheckers |
